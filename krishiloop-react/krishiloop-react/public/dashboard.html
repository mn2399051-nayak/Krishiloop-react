Google Cloud Setup Instructions

How to obtain and restrict your Google Maps API key

  1. Open the Google Cloud Console → Credentials.
  2. Create or select your project and click + Create Credentials → API key.
  3. Enable the following 4 APIs in your project: Maps JavaScript API, Places API, Directions API, and Geocoding API.
  4. Security Best Practice: Under Application restrictions, restrict the key to HTTP referrers (e.g., your domain or localhost/*).
  5. Under API restrictions, restrict the key to only the 4 APIs listed above to protect your quota.
Note on Billing: Usage of Google Maps Platform products and services may incur costs against your Google Cloud project billing account. For zero-cost prototyping, Google provides free monthly usage credits or a Maps Demo Key.
